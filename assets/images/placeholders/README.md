# assets/images/placeholders/

Emplacement prévu pour les photos génériques utilisées temporairement
(ex. avatars de témoignages). Dans cette version, ces zones sont remplacées
par des `.media-placeholder` CSS — aucune image n'est requise pour que le
site fonctionne.

## Fichiers attendus (facultatifs, phase 1)

- `testimonial-01.webp`, `testimonial-02.webp`, `testimonial-03.webp` — 200×200px, portraits carrés des futurs clients ayant laissé un témoignage.

Format WebP recommandé pour toutes les images finales (section 30 du brief).
