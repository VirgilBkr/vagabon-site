# assets/images/brand/

Emplacement des fichiers officiels de la charte graphique Vagabon (section 6
du brief). Aucun fichier n'est présent dans cette version locale : le HTML
affiche des placeholders (`.media-placeholder`) tant que ces fichiers ne
sont pas déposés ici. Ne jamais recréer le lettrage avec du texte/une police.

## Fichiers attendus

**Mot-symbole complet (lettrage original, jamais recréé en texte) :**
- `vagabon-wordmark-black.svg` — logo noir sur fond blanc
- `vagabon-wordmark-white.svg` — logo blanc sur fond noir (thème sombre, usage principal)
- `vagabon-wordmark-blue.svg` — logo bleu (#008AC9) sur fond blanc

**Monogramme :**
- `vagabon-monogram-black.svg`
- `vagabon-monogram-white.svg`
- `vagabon-monogram-blue.svg`
- Usages : favicon, icône de menu, curseur personnalisé, loader

**Symbole papillon :**
- `vagabon-butterfly-blue.svg` — papillon bleu sur fond clair
- `vagabon-butterfly-blue-dark-bg.svg` — papillon bleu sur fond sombre
- Usage : avec retenue, page À propos et section « Philosophie » de l'accueil

**Visuel de partage social (Open Graph / Twitter Card) :**
- `vagabon-social-cover.webp` — 1200×630px

## Intégration

Une fois les fichiers déposés, remplacez chaque `<span class="media-placeholder ...">`
correspondant par une balise `<img>` (ou `<svg>` intégré) pointant vers ces
chemins. Voir README.md racine → « Où modifier le logo ».
