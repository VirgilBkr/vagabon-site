# assets/icons/

Emplacement pour d'éventuelles icônes SVG supplémentaires (au-delà des
icônes inline déjà présentes dans le HTML pour le thème, le son, etc.).
Aucun set d'icônes tiers n'est requis pour le fonctionnement de la phase 1 :
toutes les icônes actuelles sont des SVG inline dans le HTML, sans
dépendance externe.
